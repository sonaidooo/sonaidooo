This repository contains the scripts and required data files for the Honours Project "Exploring epigenetic variation in the African Population".
It includes custom code for data processing, statistical analysis, and visualisation.

Note: The reference_data directory does not contain the following files due to file size restraints:
  * clinvar.vcf.gz
  * gwas_catalog_associations.tsv

These can be downloaded via https://ftp.ncbi.nlm.nih.gov/pub/clinvar/vcf_GRCh38/ and https://www.ebi.ac.uk/gwas/docs/file-downloads respectively.
